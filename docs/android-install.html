👾 KaijiBot

两步装好你的 AI 助手

1下载安装 Termux
下载 Termux APK

下载后点击安装。如果提示"未知来源"，允许即可。

2打开 Termux，粘贴运行
curl -fsSL https://gitee.com/kaiji1126/kaijibot/raw/main/scripts/install-termux.sh | bash

或扫描二维码获取命令

安装完成后会自动进入配置向导，按提示配置 API Key 和飞书机器人即可。

⚠️ 安装完成后，请务必在手机设置中关闭 Termux 的电池优化：
设置 → 应用 → Termux → 电池 → 不限制后台
否则 Gateway 会被系统杀死。
