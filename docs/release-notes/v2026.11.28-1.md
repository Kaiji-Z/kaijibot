# v2026.11.28-1 Release Notes

## What's Changed

- revert(deps): return to the pre-pi-1.6.1 codebase; port the auth-profiles latency fix (fceb9192a4)

**Upgrade from v2026.11.27 / v2026.11.28.** Those two releases carry a breaking regression: the pi-ai 1.6.1 dependency upgrade (720bb147ed) breaks the system-prompt application in the embedded runner, so the model receives pi's bare coding-agent prompt — the bot loses its persona/identity, and its memory-recall guidance ("## Memory Recall" + the memory_search/memory_get tools' usage instructions) never reaches the model. Verified end-to-end against v2026.11.26 before this rollback. This release returns the codebase to v2026.11.26 (pi-ai 0.79.4) and keeps one improvement: the per-turn latency fix ported from `25afb29c80` (usage-only saves no longer rewrite `auth-profiles.json`, which used to invalidate the models.json fingerprint and cost ~20 s per agent turn).

If you are on 2026.11.26 or earlier there is no need to upgrade; 2026.11.28-1 is functionally v2026.11.26 plus the latency fix.

## 更新内容

本版本将代码库回退到 pi-ai 1.6.1 升级之前的状态（v2026.11.26），并保留一项每轮提速修复。**如果你在使用 v2026.11.27 或 v2026.11.28，请务必升级到本版本**——那两个版本存在人设丢失的破坏性问题。

### 回退：pi-ai 1.6.1 升级导致人设丢失（fceb9192a4）

- pi-ai 1.6.1（`720bb147ed`，2026-11-26）迁移后，嵌入式 runner 的系统提示套用失效：模型实际收到的是 pi 内置的编码代理提示，机器人失去人设/身份（自称"pi 编码代理"），记忆检索指引（"## Memory Recall" 节与 memory_search 等工具的使用说明）也无法到达模型
- 升级前（v2026.11.26）与升级后的真实对话 A/B 验证确认了这一点；升级期间发布的 v2026.11.27、v2026.11.28 均带有该问题
- 按操作者决定，在 pi 1.6 的提示词套用问题被修复之前撤回依赖升级；本版本代码基线 = v2026.11.26

### 保留：每轮提速修复（移植自 25afb29c80）

- 用量记账不再重写 auth-profiles.json——此前每次保存都使模型目录指纹失效，导致每轮对话重新规划 models.json，单轮多花约 20 秒
- 移植后在本代码基线上补丁自带测试全部通过（6/2/14），实测网关侧单轮回到约 5 秒

### 本版本不包含（随 v2026.11.27/.28 回退）

- `/btw`、PDF 抽取、图片描述、会话标题、TTS 摘要的后台模型修复（该问题在 2026.11.26 及更早版本上同样存在，与回退无关）
- OAuth 令牌刷新恢复与 MiniMax 刷新移植（旧版本原生支持刷新，不受该回归影响）
- glm-5.3 思考档位映射（旧版本按原行为运行）

### 验证

- 门禁：format:check、tsgo（0 错误）、oxlint（改动文件 0 警告）、plugin-sdk api:check（基线无漂移）、check-exports 全部通过
- 补丁测试：auth-profiles.store.save 6/6、models-json-auth-usage 2/2、json-file 14/14
- 生产环境（与本项目运行时同源）实测：人设正确、记忆检索正常（可引用 memory/dialogues 与 MEMORY.md 出处）、飞书双 WS + 微信连接正常
