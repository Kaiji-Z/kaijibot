## 更新内容

本版包含全仓库审计修复、认知层的多处线上缺陷、GLM-5.3 的思考强度支持,以及一批依赖安全修复。

### 安全

- 依赖:basic-ftp 6.2.1 → 6.2.6(修复 GHSA-5pm8-86m8-9m6r、GHSA-r4jh-29pc-gfqr:恶意 FTP 服务器的一行目录列表,或含 CR/LF 的密码,可让进程崩溃);uuid 9.0.1 → 11.1.1(GHSA-w5hq-g745-h8pq);nanoid 3.3.12 → 3.3.20(GHSA-28wg-ghj8-5hjv、GHSA-2v37-7h3g-55p8)。`pnpm audit` 归零
- 网关:认知相关的 RPC 与 tasks.list / tasks.get 校验 agentId 和 userId,不能再借 `../..` 读写存储目录之外的文件
- 微信:没有任何可信发送者记录时,私聊默认拒绝(原来空列表等于“所有人”);新增 `channels.wechat.allowFrom` 配置可信的私聊发送者
- 路由:只配置了微信的安装也会把 dmScope 提升为 per-peer,微信私聊不再与 operator 及其他发送者共用同一个会话

### 认知层

- 修复:人设(persona)的衰减在每一轮重复叠加,洞察比半衰期设定的消失得快;LLM 返回的一个非数字字段会重置整个人设文件
- 修复:GLM-5.3 模型拒绝“关闭思考”的请求(HTTP 400 / 1210),导致生产模型上所有后台单次调用返回空——洞察生成、兴趣推断、会话摘要、纠错提取、记忆整合、技能质量门
- 修复:独立 LLM 调用失败时抛出错误,而不是返回空字符串
- 修复用户归属:话题 / 线程会话解析到人而不是话题 id;纠错记录归到会话里的用户而不是回复目标;含大写字母的微信用户 id 不再被拆成两份人设;persona_change 事件只发给人设变化的那个用户;主动洞察能找到只有话题会话的用户
- 修复:主动调度器一次 tick 失败后不再停摆;隐式反馈不再把 totalExchanges 虚增;认知层或演化关闭时不再发出演化信号;行为模式(pattern)洞察把反馈画像传给洞察引擎(此前提示词是随机选的);记忆整合的配置项现在真正生效,lookbackDays 也真正限制扫描窗口
- 修复:技能草稿从纯中文领域名能得到可用的名称;以 `>-`、`|+` 块标量写法给出的描述被正确展开
- 优化:洞察里的建议写成“可供考虑的选项”而不是命令;行为模式洞察改为对用户自己思考方式的观察,语气像朋友顺口一提
- 回复:每轮注入的认知上下文不再被当成用户文本——空消息不再触发 agent,纯媒体消息保留正文

### Z.AI / GLM-5.3

- 思考强度档位现在真正到达 GLM-5.3 系列:off / minimal / low → low,medium → high,xhigh → max;默认档位是 high,默认行为不变。控制台的思考强度选择器对 GLM-5.3 显示完整档位
- 批量路径(可选,默认关闭)发出的请求与同步路径一致,并提交到正确的 `/batches` 地址

### 飞书 / 微信 / CLI

- 飞书:流式卡片更新失败不再令网关崩溃或丢失最终文本;输入状态表情移除失败不再变成未处理的 rejection
- 微信:监控的休眠可被中止,停止时不再等满整个间隔
- CLI:`kaijibot restart` 的健康等待覆盖启动慢的网关;更新检查失败不再掩盖真实错误

### 测试与工程

- 每个 src 家族都有自己的 vitest 分片配置,`pnpm test <目录>` 会落到该目录内测试文件所在的分片;一批长期失败或从未运行的测试被修复
- live 套件按生产的请求形状发送(`max_completion_tokens`,后台调用关闭思考);质量指标比较时忽略中文与拉丁文字之间的空格
- flag-diff 把两边都跳过的测试与失败的测试分开统计;CI 的发布说明使用 `docs/release-notes/v<version>.md`
- 模型扫描用的图片探针是一张合法的 PNG(此前校验块 CRC 的服务商会误报模型不支持图片输入);plugin-sdk 导出 `github-copilot-token` 子路径
